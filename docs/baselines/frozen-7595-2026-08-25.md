# The first honest 7595 baseline — 2026-08-25

**7423 / 7595 test outcomes match the pinned oracle (97.74%).**
172 mismatches across 51 files; 407 of 458 files match completely.

This is the project's first compatibility number measured under the
conditions the de-cheating work existed to establish: every one of the
458 manifest files produced real outcomes (zero coverage failures), the
numerator is a per-test count with failure messages compared, and the
run was refused a score unless the tree was clean and the anti-cheat
gates passed.

## What the number counts

Every test whose status, condition type AND failure message differ from
the oracle's is a mismatch.  A test emaxx skips where the oracle passes
is a mismatch.  A file emaxx cannot load is not partial credit — the
run aborts rather than scoring it, which is why reaching this number
took ten root-cause fixes rather than one attempt.

## How to reproduce

```
cargo run --bin compat-harness -- frozen --timeout-seconds 3600
```

Frozen mode refuses `--subject-root` and a dirty tree, runs the
anti-cheat gates first, validates the oracle binary against its pinned
hash, and re-verifies every input before it will write a summary.
