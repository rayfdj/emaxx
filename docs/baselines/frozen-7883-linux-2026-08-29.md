## How this run came to be

The first attempt aborted at test/src/process-tests.el: the file's
top-level `(dns-query "google.com")' exposed emaxx resolving named
:service strings to port 0 (ledger finding 134), the load died on
sendto's EINVAL, and frozen mode's outcome-coverage contract refused
to score a 0-outcome file.  No score from that run is recorded.  This
run is the rerun after the fix, on the clean tree that also carries
the finding-133 where-is ordering fix — and test/src/keymap-tests.el
matches fully here, confirming that fix on the frozen scoreboard
(Darwin's 08-29 document records the same test as its one regression,
measured before the fix existed).

proced-tests, inotify-tests, lcms-tests, server-tests, mml-sec-tests,
python-tests — almost all features the tty-only first-era oracle

real, newly measurable Linux work, on the fix queue like everything
else in this list.  In the other direction, eglot-tests mismatches

between the machines, so the eglot cluster's size is a
per-platform fact, not a contradiction.
