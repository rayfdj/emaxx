Round 32: occur on the glass -- and the truths its prefix column told

The isearch battery deepened (fail/wrap, word search, the search
ring), query-replace's y/n/! loop and replace-string already rendered
cell-for-cell; occur did not, and the three cells it missed each led
somewhere real:

- display-supports-face-attributes-p answered nil unconditionally, an
  honest batch answer that starved the live tty:
  face-differs-from-default-p came out nil for every face, so occur
  dropped its `list-matching-lines-prefix-face' and the line-number
  prefixes lost their shadow.  The predicate now ports
  tty_supports_face_attributes_p for the frontend's terminal class --
  bold, italic, inverse, and strike-through pass, dim and underline
  fail the capability test exactly as GNU answers on this terminal,
  colors must resolve on the palette (tty-color-translate) and differ
  case-insensitively from the default face's (face_attr_equal_p) --
  while batch keeps GNU's nil.

- The tty overlay arrow: a variable in `overlay-arrow-variable-list'
  holding a marker overlays its string ("=>", or the symbol's
  `overlay-arrow-string' property) over the first cells of the row
  that starts the marker's line, painted after the face spans land so
  the arrow's cells carry the default face over the prefix's shadow
  -- occur-mode-goto-occurrence and next-error mark the current locus
  this way.

- Detection of pure-ASCII bytes decides nothing: GNU records
  `undecided' with the detected eol variant, whatever the coding
  priorities say (prefer-utf-8 cannot even be preferred, and a
  preferred utf-8-auto still answers undecided-unix); ours answered
  prefer-utf-8-unix.  The distinction is Lisp-visible in occur's mode
  line: occur copies the searched buffer's coding through
  set-buffer-file-coding-system, whose merge with the buffer default
  fires only for undecided -- so GNU's *Occur* shows the utf-8 `U'
  where ours showed `-'.  undecided's own mnemonic is `-'
  (coding.c:12281), not the `?' the bootstrap table had.

The battery gains isearch-fail-wrap, isearch-word, isearch-ring,
query-replace, occur-isearch, occur-goto, and replace-string (122
scenarios).
